いつも遊んでいただきありがとうございます。今回のアップデートでは、次の不具合を修正しました。

・ゲームを最後まで遊んだときに、進み具合のバーが100%にならない問題を修正

・アプリを起動した直後に、実績やコレクションの画面で合計スターが0と表示される問題を修正
・ほかのアプリや電話から戻ったときに、BGMが止まったままになる問題を修正
・本体の消音スイッチがオンのときは、音が鳴らないようにしました
