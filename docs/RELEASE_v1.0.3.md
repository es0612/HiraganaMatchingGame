## What's New

### ja（PO 承認済み 2026-11-01）
いつも遊んでいただきありがとうございます。今回のアップデートでは、次の改善を行いました。

・音のボタンを押すと、ひらがなを読み上げるようにしました
・まちがえたときに、正解の絵に印を付けて、正解のことばを読み上げるようにしました
・小さいiPhoneや大きい文字の設定で、3つ目の選択肢の絵やことばが隠れていたのを直しました
・「を」の問題を「ほんを よむ」のような文で出すようにしました
・文字を大きくする設定で、画面が崩れていたところを直しました
・ホーム画面をスクロールしたとき、見出しが時計と重なっていたのを直しました
・プレイ中に表示するスターを、難易度に合わせて正しく出すようにしました

（TestFlight で消音 ON でも声が出たら足す。PO 承認済み）
・消音モードのときも、音のボタンの読み上げは聞こえるようにしました
